## 六次修改：托盘点击切换窗口（2026-11-24）

用户要求"点击托盘图标显示，再次点击就关闭"。`Program.cs` 改动：

- `OpenMouseSettings()` 记录 form 到 settingsForm，并订阅 `FormClosed` 事件在窗口关闭（含鼠标断开自动关闭）时清空引用。

### 重要坑
- 编辑 `Program.cs` 时用 Python heredoc 做字符串替换，**两次把文件写成了二进制乱码**（0x02DA 开头）。原因：文件是 CRLF 换行，脚本里 `nl.decode()`/`open(...,'w',encoding='utf-8-sig',newline='')` 组合处理不当。最终解法：从备份 `/tmp/ghelper-backup-before-sync/Program.cs` 恢复后，改用**纯字节操作**（`open(...,'rb')` 读取、old/new 字符串 `.replace('\n','\r\n').encode('utf-8')` 后 replace、`open(...,'wb')` 写回），一次成功。
- 教训：编辑 CRLF 的 C# 文件时，Edit 工具会因换行不匹配失败；Python 脚本务必用字节级操作，避免 encode/decode 往返。
